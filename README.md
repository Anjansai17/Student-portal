# 🎓 Student Portal

A web-based Student Portal developed using Python, Flask, HTML, CSS, and JavaScript. It provides a simple interface for students to access academic information and student-related services.

##  Features

-  Student Dashboard
-  Student Profile Management
-  Timetable Management
-  Attendance Tracking
-  AI Learning Materials
-  AI Learning Videos
-  Assignment Management
-  AI Quizzes
-  Marks and Academic Information
-  Notifications
-  Login and Registration Pages

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Tools:** Visual Studio Code, Git, GitHub

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Anjansai17/Student-portal.git
cd Student-portal
```

### 2. Install dependencies

```bash
pip install flask
```

Install any other dependencies required by the project.

### 3. Run the application

```bash
python app.py
```

### 4. Open in your browser

Visit:

```text
http://127.0.0.1:5000
```

## 🎯 Project Objective

The objective of this project is to develop a centralized web application that helps students access academic information and learning resources through a user-friendly interface.
